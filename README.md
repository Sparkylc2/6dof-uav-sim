# 6dof-uav-sim
A basic 6 dof sim based on Small Unmanned Aircraft: Theory and Practice by Beard and McLain

The notes attached show my own working while looking at the text book, and functions implementing stuff from the textbook will have relevant sections reference in the comments.

I hope to have the time to expand this further and follow more parts of the textbook + my ideas, however for now I aim simply to implement the flight model, flight dynamics, control dynamics, and sensor approximations
